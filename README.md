# Table Control

Сайт концепта для хакатона TCH: керамический объект на столе ресторана с двумя сенсорными сторонами **FOCUS** и **EXPERIENCE**. Гость одним касанием выбирает, хочет он спокойствия или впечатлений, а официант видит режим стола у себя на телефоне.

Прод: https://table-control.vercel.app

## Что на странице

- Проблема, решение и меню впечатлений
- Интерактивное демо: объект, экран зала и телефон официанта
- Устройство в разборе, распиновка Raspberry Pi Zero 2 W, расчёт батареи, схема системы
- Себестоимость устройства, бюджет пилота и калькулятор внедрения
- План проверки гипотезы и критерии успеха

## Стек

Один файл `index.html`: HTML, CSS и JavaScript без сборки. Анимации на GSAP 3.12.5 и ScrollTrigger с cdnjs, шрифты с Google Fonts.

## Запуск локально

```bash
python3 -m http.server 4191
```

Затем откройте http://localhost:4191.

## Деплой

```bash
npx vercel deploy --prod --yes
```
